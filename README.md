# Smart Traffic Signal Optimization System

## Project Overview

This project implements a Smart Traffic Signal Optimization System using Python, Tkinter, OpenCV, NumPy, and Pillow.

The system analyzes traffic scenarios, estimates traffic density from images, calculates priority scores, and optimizes traffic signal timings using a Rule-Based Artificial Intelligence approach.

## Features

* Traffic scenario selection using images
* OpenCV-based traffic density estimation
* Priority score calculation
* Rule-Based AI decision engine
* Emergency vehicle priority override
* Traffic Analysis Dashboard
* Traffic Report Generation
* Standalone Windows EXE deployment

## AI Logic

Priority Score = (Vehicle Count × 2) + Waiting Time

The system uses predefined IF-THEN rules to determine the optimal green signal duration.

## Emergency Vehicle Handling

When an emergency vehicle is detected, the system activates an emergency override mechanism and immediately assigns maximum signal priority.
